How to order

  1. Tap the button and type your message

Questions

How does it work?

Pick a card, type the message you want printed inside, then enter the address of the person it is for. We print it on thick matt card, put it in a kraft envelope and post it straight to them.

When will it arrive?

Cards are printed within 1-3 working days and sent Royal Mail. Allow 2-5 working days in total, so order a few days before the birthday.

Can I leave the inside blank?

Yes. Leave the message box empty and the inside stays blank. Handy if it is coming to you so you can write it yourself: just put your own address.

What size is it?

7 x 5 inches (178 x 127 mm), folded, on 324gsm matt fine-art card, with a kraft envelope.

Do you post outside the UK?

Not yet. UK addresses only for now.

Something went wrong?

Email hello@tchworks.co.uk with your order email. If it's damaged, misprinted or lost we'll reprint it or refund you.
