Ask each tied team to write a number. The closest answer wins.

How to run it

  • Print one quizmaster copy for yourself and one answer sheet per team per round. Black and white is fine.
  • Read each question twice. At the end of the round, teams swap sheets and mark each other's while you read the answers.
  • Let each team play a joker on one round, declared before it starts, to double those points.
  • Six to eight rounds make about a 90-minute night.

Yes. The team answer sheet has a team name line, a joker box, ten numbered answer lines with a score box each and a round total, so it works for any 10-question round. Cross out the round title or write your own above it.
