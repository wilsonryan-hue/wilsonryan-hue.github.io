2a. On iPhone

  1. Open this page in Safari.
  2. Add to my iPhone calendar
  3. Tap Add All, choose a calendar if asked, then Done.

Each prompt has an alert built in. Check Settings › Notifications › Calendar is switched on.

2b. On Android (Google Calendar)

  1. Download the file
  2. On a computer, or in your phone's browser with Desktop site ticked, go to calendar.google.com.
  3. Create a new calendar for it: Settings › Add calendar › Create new calendar, call it 'After-School Questions'.
  4. In that calendar's settings, under Event notifications, add a notification at 0 minutes. (Google ignores the alerts inside imported files, so this step makes the prompts pop up.)
  5. Go to Settings › Import & export › Import, choose the file, pick your new calendar, and tap Import.

Samsung phones: you can also open the downloaded file and choose Samsung Calendar, which keeps the alerts.
